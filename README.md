# Cold Calling from Zero

A complete, free course that takes you from never having made a cold call to running consistent daily call blocks that book real meetings. Written for anyone selling to local businesses (marketing services, home services, B2B), but the method works for any cold outbound.

No fluff, no fake statistics, no manipulation tactics. Just the mechanics, the scripts, the reps, and the tracking.

## How to use this course

Read it in order. Each folder is one module and has its own README with a reading order.

| Module | What you learn |
|---|---|
| [01 - Foundations](01-foundations/) | The mindset, the anatomy of a call, the math, and the legal basics |
| [02 - Prospecting](02-prospecting/) | Building a free lead list, 2-minute research, running a call sheet, gatekeepers |
| [03 - Scripts](03-scripts/) | Openers, value statements, a full annotated script, discovery, voicemail |
| [04 - Objections & Closing](04-objections-closing/) | Handling every common objection and booking the meeting |
| [05 - Practice & Tracking](05-practice-and-tracking/) | Solo drills, AI roleplay, call review, KPIs, and a 30-day plan |

## The short version

1. Build a list of 100 local businesses (Module 2).
2. Learn one opener and one value statement cold (Module 3).
3. Drill objections until responses are automatic (Modules 4 and 5).
4. Dial 30-50 times a day, track everything, review weekly (Module 5).
5. Do not rewrite your script until you have real sample size. Just dial.

## Ground rules baked into everything here

- Never lie to a prospect or a gatekeeper.
- Respect Do-Not-Call rules and calling hours (Module 1 covers the basics; verify current law yourself).
- The ask is always small: a 15-minute conversation, not a sale on the phone.
- Rejection is the cost of the meeting. The math works if you keep dialing.
